# E-Commerce Sales & Customer Analysis

## Project Overview
This project analyzes e-commerce sales and customer
data using PostgreSQL.

## Tools Used
- PostgreSQL
- pgAdmin 4
- SQL

## Database Tables
- Customers
- Products
- Orders
- Order Details

## Analysis
- Total sales revenue
- Top-selling products
- City-wise sales
- Top customers
- Monthly revenue trends

## Skills Demonstrated
- SQL Joins
- Aggregate Functions
- GROUP BY and ORDER BY
- Subqueries
- Data Analysis
